## 做了哪些优化

1. **去掉重复**：面向过程/OOP 长文、`cin`/`cout`、`const`、`struct` 增强、静态成员说明等，只在最合适的一章讲一次。
2. **理顺结构**：每篇统一为「课程目标 → 核心内容 → 课堂小结 → 随堂练习」。
3. **修正逻辑**：如「返回值不能作为重载条件」、浅拷贝/深拷贝、虚析构必要性等，去掉原文中自相矛盾的表述。
4. **压缩冗余**：删去空洞注意事项、重复示例、过长 API 清单；保留关键代码与对照表。
5. **知识递进**：语言扩展 → 类 → 继承多态 → I/O 与资源 → 模板 → 现代特性与 STL。
